== Description ==

NOWPayments for Paid Memberships Pro is a payment gateway plugin that integrates NOWPayments cryptocurrency payment processing with Paid Memberships Pro membership plugin.

**Features:**

* Support for 300+ cryptocurrencies
* One-time payment processing
* Lifetime membership payments
* Sandbox mode for testing
* Secure webhook handling
* HMAC signature verification
* Full Paid Memberships Pro integration

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/nowpayments-for-pmp` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Make sure Paid Memberships Pro is installed and activated.
4. Go to Memberships > Settings > Payment Settings and select NOWPayments as your gateway.
5. Configure your API keys and IPN secret.

== Frequently Asked Questions ==

= Do I need a NOWPayments account? =

Yes, you need to create an account at https://nowpayments.io/ and get your API keys.

= Does this support subscriptions? =

Subscriptions are supported in the Pro add-on.

= Can I test payments? =

Yes, enable Sandbox mode in the gateway settings to test with NOWPayments sandbox environment.
